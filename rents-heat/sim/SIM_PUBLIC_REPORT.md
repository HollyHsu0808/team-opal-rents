# 公開資料下載 + 各公開資料效果的模擬（Microburbs 租金黑客松準備）

2026-11-07 清晨無人值守執行。**本報告所有「租金效果」都是假設（植入的），不是從真實租金量測出來的。** 真實的只有：地理（建物、地籍、車站、水岸、熱、樹冠、ABS）與 bond 校準的房間數係數。

檔案：
- 資料與授權清單：`public-data/_manifest/MANIFEST.md`
- 特徵表：`public-data/_derived/buildings_features.parquet`（另有 .csv），摘要在 `buildings_features_summary.md`
- 模擬：`rents-heat/sim/sim_public.py`（完整結果 `sim_public_results.csv`，壓縮表 `sim_public_summary.md`，世界參數 `sim_public_calibration.txt`、`sim_public_world_info.csv`）
- 門牌解析：`rents-heat/src/stack/parse_unit.py`，測試 12/12 通過

Spearman 相關的重點：

- 距水岸與 LST −0.44、與 UHI −0.47。
- SP 編號與 createdate 0.94。
- 樹冠與其他變數的相關都弱（|r| ≤ 0.37）。

## 3. SP 編號 → 年份校準

createdate 是進入數位地籍的日期，不是登記日：1992–93 年有大量相同日期，是批次數位化。排除這些後：
- 全部可用的 2,220 個 plan：Spearman 0.950。
- SP ≥ 45,000（2,108 個）：Spearman 0.978，87.6% 落在下包絡線 ±1 年內，7.1% 晚超過 2 年（後來重新建檔的）。
- 下包絡線推算：**SP 50,000 ≈ 1995.4、SP 80,000 ≈ 2007.8、SP 100,000 ≈ 2019.6**。
- **SP 10,000 無法推算**：這是 DCDB 上線前的號碼，createdate 只是建檔日。
- 近年大約每年 1,860 個 SP（全 NSW 的編號速度）。

查表檔在 `public-data/_derived/sp_year_lookup.csv`，圖在 `sp_year_calibration.png`。

## 4. 模擬怎麼做（全部是假設）

**世界設定**
- 65,777 戶放進上面 4,399 棟真實建物：戶數 = 面積 × 樓層 ÷ 95 m²，每棟上限 400。
- 郊區 = 真實的 SA2（30 個），街區 = 真實的 2016 mesh block（1,583 個）。
- 建物年份來自 SP 號碼。新建物在建成前沒有廣告，所以新樓自然沒有歷史。
- 門牌方案：
  - 「樓層 + 尾號」（506、G03）約 54%。
  - 流水號 1..N 約 40%：3 位數會被誤解析成樓層和尾號，產生假的 stack。
  - 字母方案（1203A）約 6%。
  - 多翼建物（兩個 SP）兩翼都有 506。
- 樓層只從解析出來的門牌得知：可觀察約 50%（目標 52%）。另外 20% 的戶門牌無法解析，所以自身歷史連不起來（**假設**）。

**租金模型**（log）
- 隨機效果：郊區 0.10、街區 0.07、建物 0.08、翼 0.04、stack 0.06、單戶 0.08、廣告雜訊 0.05。
- 房間數係數用 bond 數據：0:−0.37、1:0、2:0.32、3:0.63、4:0.92。
- 浴室 0.06、車位 0.08、樓層 0.006/層，市場指數沿用 sim_study。
- 基準 $452/週：讓官方 ladder（郊區 × 房 × 車位）的 MedAE 在校準世界剛好 $100。廣告中位數 $700。

**公開效果，三個等級：0 / 合理 / 強**（全部是假設）

| 群組 | 合理 | 強 | 單位 |
|---|---|---|---|
| 年代（age） | +1.5% | +5% | 每新 10 年 |
| 景觀（view） | +0.5% | +1.5% | 每高出鄰棟 1 層，上限 15 層 |
| 車站（station） | −1.5% | −5% | 每 km |
| 水岸（water） | −2% | −6% | 每 km，上限 2 km |
| 熱（heat） | −0.5% | −3% | 每 1 SD 的 LST |
| 樹冠（canopy） | +0.5% | +3% | 每 1 SD |
| ABS | 相關 0.5 | 相關 0.9 | 郊區效果與 ABS 2021 SA2 租金的相關 |

R4 文獻指出熱和綠地的租金證據很薄。水岸距離的係數是假設；RBA 類 hedonic 研究裡，大幅溢價主要來自「水景」，而不是距離。

**block rent map**（Microburbs 風格的街區地圖）= 街區內「街區 + 建物 + 翼 + 公開效果」的平均，再加雜訊 0.03 或 0.10。

**時間窗**
- A：訓練 ≤ 4 月，測試 5 月，用來選擇。
- B：訓練 ≤ 5 月，測試 6–7 月，只評估一次。
- S：訓練 ≤ 7 月，測試 8–9 月共 1,699 筆，模擬計分集。
- 測試集分層成 70% 有自身歷史。
- 每格 3 個種子 × 3 個效果等級 × 2 個地圖雜訊；配對 bootstrap 1,000 次。

## 5. 結果

### 5a. 方法階梯（合理等級，地圖雜訊 0.03，3 個種子平均）

Δ = 這一階的 MedAE 減上一階，負數 = 較好。括號是平均 95% CI，方括號是 CI 完全 <0 / >0 的種子數。

| 階 | B MedAE 全部 | B Δ 全部 | B Δ 無歷史 | S MedAE 全部 / 無歷史 | S Δ 全部 | S Δ 無歷史 | S 涵蓋率 |
|---|---|---|---|---|---|---|---|
| M0 官方 ladder | 93.3 | | | 90.0 / 94.2 | | | |
| M1 自身歷史 × 重複指數 | 53.0 | −40.3 (−47.6,−35.2) [3/0] | 0 | 53.4 / 94.2 | −36.6 [3/0] | 0 | 70% |
| M2 同棟同房數 comps | 48.6 | −4.4 (−7.1,−2.5) [3/0] | −28.8 (−39.7,−20.9) [3/0] | 47.5 / 63.0 | −5.9 [3/0] | −31.2 (−41.8,−21.4) [3/0] | 無歷史列的 93% |
| M3 已驗證 stack comps（收縮混合） | 48.7 | +0.1 | −0.0 | 47.5 / 62.7 | −0.1 | −0.3 (−1.9,+1.2) | 0.6% |
| G_base LightGBM（Microburbs 側特徵） | 48.0 | −0.7 [1/0] | −3.0 (−8.0,+2.5) [1/0] | 47.0 / 61.4 | −0.5 | −1.4 (−6.6,+4.6) | |
| G_all（+ 全部公開特徵） | 48.6 | +0.7 | +1.0 | 47.1 / 61.8 | +0.1 | +0.5 (−3.6,+4.2) | |
| + 舊租金閘門（>12 個月且偏離 >20%） | 49.0 | +0.4 [0/1] | 0 | 46.8 | −0.3 | 0 | 3.6% |
| + MedAE 平移（在 A 選 ±$10） | 50.3 | +1.3 [0/1] | +2.0 | 48.2 | +1.4 | +1.7 | |
| + 對齊到 $5 / $10 | 50.0 / 50.0 | −0.3 / −0.3 | | 48.3 / 48.3 | +0.1 / +0.1 | | |

這張表的讀法：
- 自身歷史（−37 到 −40）和同棟 comps（無歷史列 −29 到 −31）是唯二確定的大槓桿。
- **validated stack 幾乎用不到**：只有 0.6% 的列有用到。原因是 A 窗驗證通過的只有 174–196 棟，而且無歷史列很少在同 stack 裡有其他廣告。
- 閘門和平移都沒用。平移在 A 窗看起來有幫助（樣本內 −1.9 到 −2.4），在 B、S 卻變差，是典型的過度擬合選擇。
- 在這個世界裡，對齊到 $5 或 $10 沒有差別。

### 5b. 各公開特徵群：G_base + 一個群 vs G_base，S 窗

**有 block map 時**（3 種子 × 2 個地圖雜訊 × 3 個效果等級）：
- **全部列（n = 1,699）**：所有群、所有效果等級，Δ 都落在 −0.4 到 +0.7 之間，沒有任何一個種子的 CI 排除 0。
- **無歷史列（n = 510）**：Δ 在 −1.6 到 +1.8 之間，CI 約 ±4，同樣全部包含 0。**效果 0 和效果強看起來一樣。**
- **無歷史且沒有同棟 comps（n ≈ 34）**：CI 寬 ±20 到 ±35，什麼都看不出來。

B 窗（n = 2,041 / 612）的結論相同。

**正對照（大樣本診斷）**：把 8–9 月所有廣告（n ≈ 2,477）都當成「無歷史、也沒有同棟 comps」的新樓來打分，模型和上面相同。

| 設定 | 效果 0 | 合理 | 強 |
|---|---|---|---|
| 有 map（雜訊 0.03），全部公開特徵 | −1.1 (−3.4,+1.3) | −1.0 | −2.0 (−5.2,+1.2) [0/3 顯著] |
| 有 map（雜訊 0.10），全部公開特徵 | −0.2 | −1.9 | **−5.7 (−9.1,−2.3) [3/3]** |
| 沒有 map，全部公開特徵 | −2.7 [2/3] | −2.8 [1/3] | **−10.9 (−14.8,−6.3) [3/3]** |
| 沒有 map，只加年代（SP） | −0.8 | −0.3 | −4.8 (−9.0,−1.0) [2/3] |
| 沒有 map，只加熱 + 樹冠 | −1.6 | −1.4 | −3.6 [2/3] |
| 沒有 map，只加水岸 / 車站 / 景觀 | −2.3 / −1.4 / −0.9 | −0.4 / −0.7 / +0.5 | −2.1 / −1.5 / −1.8 |
| 沒有 map，只加 ABS | +0.2 | +1.2 | +0.4 |

- 這證明管線沒有壞：公開特徵確實能抓到植入的效果。條件是三個同時成立：效果要強、沒有其他資料已經吸收它、樣本要大。
- 「效果 0、沒有 map」也有 −2.7，這不是植入效果。距車站、距水岸、LST 這些連續值組合起來，等於替建物蓋了一個「位置指紋」，模型可以拿它查出同一棟在訓練資料裡的建物效果。所以真正歸因於植入效果的大約是「強 − 0」≈ −8。
- ABS 在所有設定都沒用。SA2 本身就是郊區類別，ABS 只是郊區的另一種編碼。

### 5c. 1,699 筆計分廣告能看出什麼

- 能看出：自身歷史、同棟 comps，CI 遠離 0。
- 看不出：任何公開特徵群，就算是「強」效果也一樣。原因有兩個：
  1. 約 70% 的計分列有自身歷史，剩下的 93% 有同棟 comps，建物層級的效果已經被吸收。
  2. 真正缺資料的列只有約 34 筆；要看出 $5 的差異，CI 必須小於 ±3，大約需要 2,000 筆以上這類列。
- 地圖雜訊 0.10（地圖較差）時，公開特徵才開始有一點價值（強效果時 −5.7）。所以 **block map 的品質是決定公開資料有沒有用的關鍵**，這呼應第 4 輪的批評。

## 6. 植入 vs 量測：誠實的界線

- 植入的（假設）：所有 β、各個 sd、20% 門牌無法連結、70% 測試列有歷史、門牌方案比例、每戶 95 m²。結果的大小完全取決於這些假設。
- 量測的（真實）：地理特徵本身、特徵之間的相關、SP → 年份的關係、ABS 2021 租金、bond 的房間數係數、ladder ≈ $100 的校準目標。
- 所以這份報告能說的是：在合理的假設範圍內，公開資料對計分 MedAE 的影響小到 1,699 筆測不出來；它唯一可能有用的地方，是沒有歷史也沒有同棟 comps 的新樓，或地圖品質差的情況。它**不能**說 Sydney 的水岸或熱效應是多少。
- 其他限制：
  - stack 收縮權重 k = 2.5 是用「已知的」sd 算的，真實資料要在 A 窗估。
  - 多翼的判定靠 SP 是否相交，可能高估。
  - 1,296 棟 yes_ge3 可能是辦公樓。
  - 模擬的 ladder R² 0.77，高於 bond 的 0.53，表示模擬世界比真實「乾淨」。

## 7. 給明天的建議（依這次結果）

1. 先做自身歷史 × 重複指數，再做同棟同房數 comps：這兩步就拿到幾乎全部的增益。
2. 公開特徵只在「無歷史且無同棟 comps」的列用，例如新樓（SP ≥ 100,000、2019 年後）。真實資料進來後，先數這類列有多少；如果只有幾十筆，就跳過公開特徵。
3. MedAE 平移和 $5/$10 對齊要在 A 選、在 B 驗證；這次模擬裡兩者都沒有贏。
4. `parse_unit` 可以直接用。它的 `max_floor` 參數接 OSM levels，用來抓流水號。
